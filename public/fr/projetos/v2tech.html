Outil pour les entreprises

V²Tech COMBUSTÍVEL

Pour que les sociétés de bus, les transporteurs et les flottes au Brésil vérifient si le prix du gazole, de l’essence ou de l’éthanol facturé par le distributeur est cohérent.

Ouvrir v2tech.app.br

Le défi

Quand un nouveau prix de carburant arrive, savoir s’il est juste demande un long calcul : le prix de Petrobras, les taxes, le biodiesel, le fret, la marge du distributeur et les intérêts du délai de paiement. Ce calcul vivait dans un tableur.

Ce qui a été fait

  • Le client indique où il reçoit le carburant, ce que dit le contrat et le prix proposé ; le site répond si le prix est cohérent, quel serait le juste prix et ce que l’écart représente par mois.
  • Des comptes par entreprise, avec une équipe : tout le monde voit les mêmes contrats et calculs.
  • Les contrats enregistrés sont recalculés chaque jour, avec une alerte par e-mail quand le prix payé sort de la fourchette ou qu’une hausse arrive.
  • Un rapport PDF d’une page et, quand le prix est élevé, une lettre prête pour le distributeur.
  • Une carte publique du juste prix par État, un simulateur de scénarios et un calendrier des hausses.
  • Une API pour que les systèmes de flotte consultent le juste prix tout seuls.

Sous le capot

  • Le calcul se fait sur le serveur : le navigateur du client ne reçoit que le résultat.
  • Les données de marché (Petrobras, la Banque centrale du Brésil, le régulateur ANP) sont mises à jour chaque jour par un robot qui refuse les valeurs invraisemblables.
  • Sauvegarde quotidienne chiffrée.
