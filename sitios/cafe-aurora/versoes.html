Uma cafeteria, três jeitos de fazer

O mesmo prompt foi para três IAs (ChatGPT, Gemini e DeepSeek). Fiquei com a versão do DeepSeek, estudei e reconstruí o código passo a passo em CSS puro; depois refiz a mesma página com Bootstrap 5.3 e com Tailwind CSS 3.4. Aqui estão as três lado a lado.

CSS puro Bootstrap 5 Tailwind CSS

As três estão em 13 línguas: troque o começo do endereço, por exemplo /en/bootstrap/ ou /ja/tailwind/.

Quanto cada uma pesa

  • Bootstrap: dois terços do peso são do próprio Bootstrap (30 KB de CSS e 23 KB de JavaScript), mesmo usando só o grid, a barra de navegação e alguns utilitários. O CSS próprio cai para a metade, porque o grid já vem pronto.
  • Tailwind: o compilador deixa só as classes que a página usa: 0,7 KB. O layout passa para o HTML (grid gap-6 sm:grid-cols-2), e o CSS próprio fica só com o tema neon e as animações.
  • CSS puro: nada de fora; tudo o que a página faz está escrito à mão, o que dá mais trabalho e mais controle.

O mesmo cartão do cardápio, nos três

Quando usar cada um

CSS puro

Quando o visual é muito próprio (como o neon e a padaria) e o site precisa ser leve. Pede mais tempo, mas não carrega nada que não use.

Bootstrap

Quando é preciso montar rápido telas comuns (formulários, menus, modais) e o peso extra não importa, como num painel interno.

Tailwind

Quando o time quer o layout visível no HTML e um CSS final pequeno. Exige um passo de compilação e um HTML mais carregado de classes.
